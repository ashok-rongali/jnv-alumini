# JNV Alumni Portal

Responsive, multi-page static portal prototype for members and administrators. Open `index.html` in a browser.

## Demo login

- Any valid email and non-empty password opens the static administrator dashboard.

The portal includes separate HTML pages for dashboard analytics, jobs/events/announcements, member records, role permissions, member profile, and settings. Static page data is stored as JSON objects or arrays in `application/json` script blocks inside the relevant HTML page. No local or session storage is used.

Authentication, authorization, member records, file uploads, and publishing must be connected to a secure backend before production use.
