# JNV Alumni Association Website

Responsive static site built with HTML5, CSS3, Bootstrap 5, Bootstrap Icons, and vanilla JavaScript.

Open `index.html` in a browser. Shared components, mock data, interactions, and future FastAPI functions are centralized in `assets/js/app.js`.

The project contains Home, About, Alumni Directory/Profile, Events/Details, Blogs/Details, Announcements/Details, Contact, Register, Login, Privacy, Terms, and 404 pages.
